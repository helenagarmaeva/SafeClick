# Изображения для сайта SafeClick

Загружайте изображения в эту папку:

1. Нажмите **Add file → Upload files** на GitHub.
2. Перетащите JPG, PNG или WebP в окно загрузки.
3. Нажмите **Commit changes**, чтобы сохранить файл в ветке `main`.
4. Сообщите в чате имя загруженного файла, чтобы добавить его на страницу.

Для фотографии устройства на джинсах используйте имя `safeclick-lifestyle.jpg`, если исходный файл в формате JPG. Для PNG используйте расширение `.png`.

Используйте короткие имена латинскими буквами, без пробелов, например `safeclick-lifestyle.jpg`.

Файлы в публичном репозитории доступны всем. Сохранение изображения в этой папке само по себе не добавляет его в дизайн страницы.
